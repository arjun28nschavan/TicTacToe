# Tic Tac Toe – Neon Edition

A modern neon-themed Tic Tac Toe game built using HTML, CSS, JavaScript, and Bootstrap.  
Includes smart AI, confetti animations, glowing UI, and mobile responsiveness.

## Features
- Player vs Player
- Play vs Computer (Medium AI)
- Neon glowing theme
- Confetti winner animation
- Winning line highlight
- Arcade background music (toggle)
- Responsive design
- Reset & New Game options

## Technologies
- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Canvas-Confetti

## Deployment
Hosted easily on Vercel:
1. Import repo → New Project
2. Click Deploy.
